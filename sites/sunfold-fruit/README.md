# Sunfold Fruit Co.

A responsive, one-page storefront concept for a small-batch dehydrated fruit business. It includes the mango-and-banana artwork, four sample products, a persistent basket, and an order request via email.

## Preview

From this folder, run:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Customize

- Replace the sample brand name, story, product details, prices, and email address in `index.html` and `script.js`.
- Product photography is loaded from Unsplash; replace the image URLs in `script.js` and `index.html` with your own product photography before publishing.
- Update colors, typography, and responsive layouts in `styles.css`.
- The order button opens an email draft; connect a payment and fulfillment provider before accepting online payments.
